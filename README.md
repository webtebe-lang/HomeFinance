# Домашние финансы — сайт

Одностраничный сайт приложения «Домашние финансы» для Android: описание
возможностей, скриншоты, инструкция по установке и скачивание APK.

Сайт статический: HTML, CSS и немного JavaScript без сборки и зависимостей.
Его можно открыть локально или опубликовать на GitHub Pages.

## Структура

```
index.html                      страница
assets/css/style.css            стили
assets/js/main.js               анимации и галерея
assets/img/screenshots/         скриншоты приложения (1080×2400)
assets/img/favicon.svg          иконка сайта
assets/img/og.png               изображение для соцсетей
```

APK скачивается по публичной ссылке Google Drive, указанной в `index.html`.

## Как обновить ссылку на приложение

1. Замените ссылку Google Drive во всех кнопках в `index.html`
   (шапка, первый экран, блок установки, подвал и нижняя панель).
2. Обновите версию, размер и контрольную сумму в блоке установки.
3. Для нового APK проверьте сумму командой
   `Get-FileHash путь\к\приложению.apk -Algorithm SHA256`.

## Локальный просмотр

```powershell
python -m http.server 8000
```

Затем откройте <http://localhost:8000>.
